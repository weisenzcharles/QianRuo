# 租赁项目详细功能规格书

版本：V3.0 研发详细版（1.0 需求基线）
日期：2026-07-28

本规格书用于后续开发拆解，覆盖功能规则、字段、权限、安全、状态、接口与验收。最新权威需求来自 `1.0-迁渃—多维订单库存管理系统.docx`、`1.0-总后台-迁渃.docx` 和 `1.0-会员后台-迁渃.docx`，需求优先级与当前实施差异见[1.0 需求基线与实施差异](./1.0需求基线与实施差异.md)。

## 术语与接口边界

- **会员**：工程统一称为商户主体，对应 `member_id`；会员后台对应 `merchant-web`，总后台对应 `admin-web`。
- **平台系统接口**：使用 `/admin/**` 等平台专属命名空间，由平台服务提供，不与商户 Controller 复用。
- **商户接口**：全部使用 `/merchant/**`，登录态必须携带可信 `tenant_id + member_id + warehouse_scope`，不得从请求参数切换主体。
- **客户开放接口**：微信小程序、公众号或 H5 使用独立短期会话和权限域，不复用平台或商户后台令牌。
- **实现状态**：本文描述目标规格；“已有表”“已有页面”不代表功能已经实现，实际状态以项目架构图和阶段完成状态为准。

## 全局安全与商业系统基线

- **身份认证**：后台账号必须登录；支持 30 天免登录的公众号/小程序会话必须采用短期访问令牌 + 可续期刷新令牌；异常设备、异地或高风险操作要求重新验证。
- **权限控制**：所有 API 必须做服务端权限校验，不能只依赖前端隐藏按钮；权限维度至少包含主体、角色、仓库、订单归属、联盟关系、市场帖子归属。
- **数据隔离**：所有核心表必须带 tenant_id/member_id；查询默认强制带租户条件；平台管理员跨租户查询必须落审计日志。
- **敏感信息**：客户姓名、手机号、地址、支付宝手机号、芝麻分、微信二维码属于敏感数据；列表默认脱敏，详情按权限解密显示；导出需审批或二次确认。
- **输入校验**：手机号、金额、数量、日期、SN、单号、URL、备注、模板文案都要做格式、长度、枚举和非法字符校验；自由文本禁止脚本注入。
- **文件上传**：视频/图片仅允许白名单格式；校验 MIME 与扩展名；限制大小、时长、分辨率、数量；文件私有存储，访问走带权限的临时 URL。
- **接口防刷**：登录、验证码、物流查询、站内私信、上传、市场发布、举报、推广注册必须限频；高频接口按用户、IP、设备、租户多维限流。
- **资金安全**：充值、扣费、佣金、保证金、发票金额必须用不可变流水；禁止直接覆盖原流水，只能做冲正/调整记录。
- **审计日志**：订单核心字段、SN 状态、库存扣减、仓库迁移、权限修改、客户敏感信息查看、财务变更、市场处罚都必须记录操作者、时间、前后值、IP。
- **留存规则**：审计日志及关联原始文件至少保留 3 年；未办结纠纷和争议证据永久保留；普通浏览不记操作审计。
- **删除与恢复**：商户普通业务删除进入回收站保留 30 天，可按条恢复；财务、审计、协议、合同和争议证据不进入普通删除流程。
- **数据备份**：数据库每日备份，备份包保留 7 天；文件对象存储多副本；审计和财务日志支持按月打包。
- **统一时区**：数据库连接、JVM、JSON 序列化和前端展示统一使用 Asia/Shanghai，禁止各模块自行转换时间。

## 角色与权限矩阵

- **平台超级管理员**：平台级所有会员、订单统计、库存统计、财务、票据、风控、系统配置；可看平台汇总；涉及客户明文资料需单独授权与操作日志
- **平台运营管理员**：会员审核、公告、内容治理、经营分析和推广配置；不能直接导出客户敏感信息；不能改财务流水原始记录
- **平台财务管理员**：账户、分账、提现、发票、红冲、退款和财务报表；不能修改商户订单和库存业务数据
- **平台售后审核员**：售后、赔付、纠纷材料、调解和工单处理；冻结、扣款和退款需独立权限
- **平台客服专员**：客服工单、认证材料补充、消息通知和进度沟通；无资金扣款和发票操作权限
- **会员主账号**：本主体下仓库、商品、订单、套餐、员工、模板、视频存储、快递余额、增值服务；只能访问本主体数据；联盟/市场数据按授权展示
- **会员财务**：充值、快递扣费、增值服务、记账簿、发票状态；不能操作订单发货、SN 删除、员工权限
- **仓库管理员**：本仓订单、库存、备货、发货、验机、扫码核销、盘点；默认只能看授权仓库；跨仓调拨需指令或审批
- **普通员工**：录单、查看被授权订单、上传视频、备注已阅；敏感字段脱敏；关键字段修改需保留编辑记录
- **联盟成员**：联盟共享库存、联盟协助订单、承接/转派/拒绝、公众池；客户信息脱敏；不在线支付；不可看非联盟库存
- **终端客户**：微信小程序订单查询、归还下单、开箱视频上传、发货视频查看；手机号验证后只可访问匹配订单；不可修改归还仓库
- **推广员**：推广码、邀请记录、佣金记录、优惠包资格；需主体唯一与有效用户规则校验
- **会员类型权限**：个人会员无接单权限；普通企业会员可承接互助订单；入驻会员可承接互助订单和小程序散客单；会员类型不替代用户角色和仓库权限

## 核心数据模型

- **Tenant/Member**：id, type, auth_status, legal_subject_id, nickname, vip_level, storage_quota, settings；会员主体；所有业务数据的隔离根。
- **User**：id, member_id, role_id, phone, wechat_openid, status, last_login_at；会员员工或平台人员；绑定权限组。
- **Role/PermissionGroup**：id, member_id, role_name, warehouse_scope, feature_scope；控制菜单、按钮、仓库、敏感字段。
- **Warehouse**：id, member_id, name, contact, phone, province, city, address, pickup_rule；实体仓与联盟共享仓；归还仓不可被客户修改。
- **Product**：id, category, brand, model, memory, condition_level, image, cost, sale_price；商品标准库；品牌型号由系统固定，会员维护常用列表。
- **AssetSN**：id, product_id, sn_code, warehouse_id, status, purchase_at, warranty_until, insurance_until；单台设备，可扫码，可追溯。
- **AccessoryItem**：id, product_id, mode, virtual_id, status, warehouse_id；配件 SN 模式或总数模式生成的 ID。
- **PackageTemplate**：id, member_id, platform, product_id, package_name, bom_json, enabled；套餐配置，作为录单模板与可租数量计算依据。
- **RentalOrder**：id, member_id, channel, shop_name, customer_id, lease_start, lease_end, status, rent_amount；订单主表，驱动库存、物流、视频、售后和财务。
- **OrderItem**：order_id, product_id, package_id, sn_id, accessory_items, quantity；订单商品明细，SN 可后绑定。
- **LogisticsOrder**：id, order_id, direction, carrier, tracking_no, pickup_time, route_status, fee；发货/归还物流，状态全链路展示。
- **MediaAsset**：id, order_id, type, file_key, detected_sn, uploaded_by, retention_until；发货视频、收货视频、开箱视频、验机图片。
- **InventorySnapshot**：date, member_id, warehouse_id, product_id, free_qty, occupied_qty, expected_qty；每日独立重算库存，不沿用前一日数值。
- **InventoryLedger**：id, sn_id/accessory_id, from_status, to_status, reason, ref_type, ref_id；库存状态流水；账实核查依据。
- **AfterSalesCase**：id, order_id, type, compensation_amount, lost_items, progress, status；售后、丢失、损坏赔付。
- **FinanceLedger**：id, member_id, type, amount, direction, ref_order_id, pay_channel, invoice_status；财务不可变流水。
- **MarketPost**：id, member_id, board, product_fields, condition, qty, city, tags, status；周转市场标准化帖子。
- **AllianceOrder**：id, initiator_id, receiver_id, settlement_price, masked_customer_json, status；联盟协助订单，只记账不在线支付。
- **AuditLog**：actor_id, action, object_type, object_id, before_json, after_json, ip, created_at；所有高风险操作记录。
- **Agreement/AgreementVersion**：agreement_id, scene, terminal_scope, version_no, effective_at, content, immutable；协议、隐私、物流免责和互助规则版本。
- **AgreementAcceptance**：subject_type, subject_id, agreement_version_id, accepted_at, ip, user_agent；用户或访客对具体版本的确认记录。
- **MemberCertification**：member_id, member_type, status, submitted_at, reviewed_by, review_remark；一轮认证申请及审核状态。
- **CertificationMaterial**：certification_id, material_type, file_id, retain_policy；身份证、营业执照、芝麻分和人脸核验材料。
- **WorkTask/Assignment/Submission/Review**：任务模板、用户/仓库指派、完成说明、已阅状态、抽检备注和评分。
- **RecycleRecord**：member_id, object_type, object_id, snapshot_json, deleted_by, expires_at, restore_status；30 天可恢复删除快照。
- **InternalNotice**：member_id, title, content, effective_at, offline_at, audience, status；商户内部通知。
- **KnowledgeArticle/Version**：member_id, category_id, audience, content, attachment_ids, version_no, retention_until；私有知识库及历史版本。
- **ServiceTicket/TicketEvent**：ticket_type, ref_type, ref_id, assignee, status, event_type, detail；认证、售后、开票、赔付和退款统一工单时间线。
- **CompensationTemplate/DisputeCase**：会员赔付条款、纠纷证据、90 天调解、双方确认和资金冻结关系。
- **FinanceAccount/AccountLedger/FundFreeze**：按增值余额、履约保证金、租金/分账资金分户记账，冻结和扣款追加流水。
- **PaymentSplit/WithdrawalApplication**：支付分账、结算、提现审核、手续费和到账记录。
- **InvoiceApplication/InvoiceRecord**：订单开票申请、发票、补票、红冲和原订单关联。
- **OrderContract/ContractEvidence**：订单合同版本、签约人、签约时间、签约 IP 和证据文件。
- **IntegrationProvider/CallLog/TimingSample**：外部接口配置、调用结果和历史线路时效样本。
- **StorageQuotaLedger/AlertEvent/BackupRecord**：容量变化、业务告警和备份执行记录。

## 状态机定义

- **SN 状态**：在库可售、已占用、已备货、发货在途、租用中、归还在途、已签收待验机、售后中、报修、损坏、出售出库、丢失、停用；所有变更进入 InventoryLedger，禁止无流水改状态。
- **订单状态**：待发货、已备货、发货在途、租用中、归还中、已签收、逾期归还、发货逾期、到货逾期、售后中、可完结、已完结、已取消、追回中；状态变更应由业务动作触发，不能任意手工跳转。
- **物流状态**：待下单、待揽收、运输中、抵达本省、派送中、已签收、退回、滞留、异常、查询中；来自承运商接口或人工确认；接口状态保留原始报文。
- **市场帖子状态**：草稿、已发布、下架、降权、举报中、违规下架、保证金扣罚、限制入驻；处罚状态必须有审核记录。
- **联盟订单状态**：待承接、已接受、已转派、已拒绝、公众池中、已发货、已完成、已取消；结算价只记账，不支付。
- **财务流水状态**：待支付、已支付、已退款、已冲正、待开票、已开票、未开票、待收发票、异常；流水不可物理删除。
- **商户认证状态**：未提交、待审核、已通过、已驳回、已冻结、已注销；已驳回可修改后重新提交，已通过后资格变更必须有审计记录。
- **工作任务状态**：待处理、已阅、处理中、已完成、未完成、超时、待质检、质检通过、质检未达标；提交和质检分别记录操作者。
- **客服工单状态**：待分配、处理中、待补充、待审核、待双方确认、已解决、已驳回、已关闭；所有状态变化追加事件。
- **纠纷状态**：已发起、材料收集中、调解中、待双方确认、已和解、调解到期、已关闭；调解到期自动解冻。
- **资金冻结状态**：待冻结、已冻结、部分扣款、已扣款、已解冻、冻结失败；冻结额度不得超过对应纠纷预计赔付额。
- **发票状态**：待审核、已驳回、待开票、已开票、已红冲；同一订单只允许存在一个成功开票结果。

## 总后台

给平台方提供会员、财务、库存、订单、微信小程序与风控总览，支撑商业化、客服与运营决策。

### 会员管理
- 业务规则：注册会员列表；个人/企业、未认证/已认证分类；近期使用情况、在线时长、录单数量、设备数量、近 1 个月设备使用次数。
- 关键字段/数据：会员 id、主体、认证资料、日活、平均在线时长、录单数、设备数、最近登录、VIP 状态。
- 安全校验/异常处理：平台管理员可看；运营可改认证状态；敏感资料查看记录审计。

### 财务综合看板
- 业务规则：会员收入合计、平台支出合计、当期净收支、票据汇总、异常账单标记。
- 关键字段/数据：增值服务收入、快递收入、平台付款、已开票、未开票、待收发票、支付渠道、订单号。
- 安全校验/异常处理：金额只能来自流水汇总；异常标记不允许删除原流水；导出需权限。

### 增值服务明细
- 业务规则：展示会员购买的增值服务订单、金额、支付渠道、发票状态。
- 关键字段/数据：服务类型、计费周期、订单号、支付单号、开票金额、未开票金额。
- 安全校验/异常处理：退款/补差必须生成冲正流水。

### 快递费明细
- 业务规则：按会员、仓库、承运商统计快递费收入与支出。
- 关键字段/数据：发货仓、承运商、单号、实际成本、会员结算价、折扣、赔付金额。
- 安全校验/异常处理：物流赔付自动识别单号，退款到会员账户并记录。

### 总库存
- 业务规则：统计所有会员设备、配件库存：租用中、发货在途、归还在途、在库可售。
- 关键字段/数据：会员、城市、仓库、商品、SN、配件数量、状态。
- 安全校验/异常处理：平台只展示统计与必要明细；客户订单信息默认隐藏。

### 库存核查评分
- 业务规则：按近 3 个月流转情况给会员库存评级，为小程序可接单量提供参考。
- 关键字段/数据：近 3 个月设备使用次数、使用设备数、总设备数、周转率、评分。
- 安全校验/异常处理：评分规则可配置；接单参考量 = 可用库存 - 租用中/发货在途/归还在途，再保守折半。

### 订单统计
- 业务规则：统计完成、取消、逾期订单，支持上月、3 个月、半年、一年、总量。
- 关键字段/数据：订单数量、渠道、城市、商品、状态。
- 安全校验/异常处理：只统计数字，不展示客户明文信息。

### 微信小程序统计
- 业务规则：统计订单卡片转发次数、转发会员、授权记录。
- 关键字段/数据：openid/unionid 脱敏、授权时间、转发次数、来源会员。
- 安全校验/异常处理：授权记录保留；客户数据管理员可看，其他角色脱敏。

### 协议管理
- 业务规则：用户服务协议、隐私政策、物流免责协议、访客告知和互助协议分别维护当前版本、历史版本和生效范围；修改必须生成新版本，可设置生效时间；新版本生效后对应终端用户下次进入必须重新确认。
- 关键字段/数据：协议类型、版本号、富文本内容、更新备注、生效时间、网页/小程序开关、确认主体、确认时间、IP、UA。
- 安全校验/异常处理：历史版本永久存档且不可编辑删除；未确认当前版本时只能访问协议确认和退出接口。

### 平台商品标准
- 业务规则：平台维护商品分类层级、品牌型号、封面图和官方定价，支持启停、排序和批量导入；商户维护常用范围和允许的三级分类。
- 关键字段/数据：父分类、层级、排序、状态、品牌、型号、封面、官方定价、导入批次。
- 安全校验/异常处理：被业务数据引用的分类或型号只能停用；批量导入逐行返回错误且不能部分污染标准库。

### 会员类型与接单资格
- 业务规则：个人会员无接单权限，普通企业会员可接互助订单，入驻会员可接互助和小程序散客单；仅完成企业或个体工商户认证后可开通接单权限。
- 关键字段/数据：会员类型、认证状态、互助接单开关、散客接单开关、变更原因、变更人和时间。
- 安全校验/异常处理：权限模板支持批量分配；资格变更写入平台管理员审计，冻结或认证失效时立即停止新接单。

### 会员认证与信用
- 业务规则：手机号注册后提交身份证、营业执照、负责人芝麻分截图和人脸核验；未认证只开放浏览；支持驳回补充、冻结、解封、黑名单、纠纷申诉和信用分事件。
- 关键字段/数据：主体、负责人、联系方式、城市、经营品类、材料文件、审核记录、信用等级、履约次数、纠纷数量、在线时长和协议版本。
- 安全校验/异常处理：认证材料永久存档；黑名单和冻结必须保存原因、操作者和时间；申诉成功通过信用事件冲正，不能直接覆盖历史分值。

### 内部通知与私有知识库治理
- 业务规则：平台可查看全平台基础统计和违规内容；只有超级管理员可按合规权限查看完整商户内容，平台只能下架，不能修改或删除商户原文。
- 关键字段/数据：商户、标题、分类、受众、附件、版本、阅读次数、下架原因和审计记录。
- 安全校验/异常处理：普通管理员只见脱敏元数据；知识附件计入商户存储配额，商户删除后不再计费但平台保留合规副本。

### 增值服务与全局参数
- 业务规则：配置会员套餐、存储包、通知包、信息发布和物流服务；统一维护站点、支付、存储、风控、发票、接口并发、导入导出模板、订单来源、脱敏和标签说明。
- 关键字段/数据：服务价格、周期、容量、上下架、支付密钥引用、回调地址、税率、并发阈值、模板版本和配置生效时间。
- 安全校验/异常处理：密钥不回显明文；配置变更审计并支持回滚到历史版本；通知包前端可隐藏但数据库保留能力字段。

### 消息与待办中心
- 业务规则：管理系统站内消息、短信/模板推送日志和平台待办；待认证、待售后、待开票、待赔付自动进入待办。
- 关键字段/数据：消息类型、接收人、业务引用、发送渠道、模板版本、发送结果、失败原因和重试次数。
- 安全校验/异常处理：发送失败进入告警；重复事件通过幂等键只生成一个待办。

### 平台角色权限模板
- 业务规则：预设超级管理员、财务管理员、售后审核员、运营管理员和客服专员；自定义角色细分查看、新增、编辑、下架、导出、审核和扣款权限。
- 关键字段/数据：角色模板、菜单权限、按钮权限、敏感字段权限、数据范围、分配账号和版本。
- 安全校验/异常处理：财务、售后、客服严格隔离；权限变更使相关会话失效并记录管理员审计。

### 三类操作审计
- 业务规则：分别记录商户员工、访客和平台管理员的高风险动作；普通浏览不记录；后台只支持查询和授权导出。
- 关键字段/数据：日志 ID、主体/账号、动作、对象、前后值、外网 IP、UA、结果、业务引用、文件引用和时间。
- 安全校验/异常处理：无编辑、删除、清空权限；至少留存 3 年，未办结纠纷和关联原始文件永久保留。

### 租客与访客统计
- 业务规则：分别统计线上访客、渠道订单租客和录入订单租客，支持手机号精准搜索和历史订单跳转。
- 关键字段/数据：访客 ID、手机号哈希/密文、来源、使用次数、完结次数和关联订单。
- 安全校验/异常处理：手机号明文仅超级管理员可见；普通管理员脱敏；录入订单租客明细不可导出，逐条查看记审计。

### 平台订单大厅与物流统计
- 业务规则：互助订单和小程序散客订单脱敏展示，按状态变色并快捷跳转售后/物流；物流按会员/访客及日/月/季/年统计下单、支付、取消和赔付。
- 关键字段/数据：订单来源、状态、会员、城市、商品、物流金额、取消金额、晚到/丢失赔付和账单。
- 安全校验/异常处理：完整订单只允许有权限管理员逐条查看；物流账单导出按财务权限控制。

### 客服工单、合同与证据
- 业务规则：所有需人工审核事项统一进入客服工单，支持分配、补充材料、处理时间线和关联资金动作；每笔租赁订单绑定对应合同和签约证据。
- 关键字段/数据：工单类型、业务引用、发起人、处理人、状态、事件、附件，合同版本、签约人、签约时间和签约 IP。
- 安全校验/异常处理：工单事件和合同证据只追加；导出合同需权限并记录审计。

### 财务、分账、提现与发票
- 业务规则：已开票和未开票收入分别统计；增值余额、履约保证金和租金/分账资金分户；支持分账、结算、提现审核、开票申请、补票和红冲。
- 关键字段/数据：账户类型、余额、冻结额、流水方向、支付渠道、手续费、到账记录、发票抬头/税号、申请状态和原发票引用。
- 安全校验/异常处理：同一订单只允许成功开票一次；资金变化只追加流水；红冲、退款和冲正必须关联原记录。

### 纠纷、保证金与风控
- 业务规则：会员自主赔付条款无需前置审核，平台仅可违规下架；纠纷按预计赔付额定向冻结，调解 90 天，到期自动解冻，双方共同确认后才能扣款。
- 关键字段/数据：条款版本、免责声明、纠纷订单、证据、预计金额、冻结流水、倒计时、双方确认和处理结果。
- 安全校验/异常处理：禁止全额冻结和单方强扣；同一会员 7 天内 3 笔无依据纠纷触发预警；保证金低于阈值禁止新增互助订单。

### 经营分析与系统运维
- 业务规则：按品牌型号、城市、会员、订单和库存生成趋势、TOP10 和地图；支持每日备份、月度日志包、容量监控和异常告警。
- 关键字段/数据：统计周期、指标口径、聚合版本、备份文件、保留期限、容量已用/剩余、告警类型和处理状态。
- 安全校验/异常处理：报表必须可追溯到原始数据；备份包保留 7 天；支付、短信、任务和存储异常自动告警。

## 首页工作台

让会员进入系统后先看到今日任务、库存风险、营收情况和地理分布。

### 今日报表
- 业务规则：今日待发、今日归还、今日到库，支持整体展示和按仓展示。
- 关键字段/数据：日期、仓库、订单状态、待处理数量、异常数量。
- 安全校验/异常处理：只展示当前用户有权限仓库。

### 汇总报表
- 业务规则：展示订单、库存、营收、逾期、售后等核心指标。
- 关键字段/数据：时间范围、渠道、商品、仓库、会员主体。
- 安全校验/异常处理：统计口径与各模块一致，不允许前端自行计算核心数据。

### 营收分析
- 业务规则：展示租金、增值服务、快递差价、赔付、出售收入。
- 关键字段/数据：收入类型、周期、商品、渠道、仓库。
- 安全校验/异常处理：普通员工不可看财务金额。

### 租用中
- 业务规则：展示当前租用中订单数量、商品、SN、预计归还。
- 关键字段/数据：订单号、商品、SN、租期、客户脱敏、仓库。
- 安全校验/异常处理：客户隐私按权限脱敏。

### 租赁地图
- 业务规则：标注客户分布、仓库位置、正在租用客户颜色区分。
- 关键字段/数据：城市、坐标、客户数量、仓库坐标、租用状态。
- 安全校验/异常处理：地图点位聚合，避免暴露客户精确地址。

### 全局我的工作台
- 业务规则：所有商户业务页面右侧提供可滚动工作台；管理可按仓库发布任务，员工和个人可自建任务；支持已完成、已阅、未完成、完成说明、超时提醒、抽检、备注和每日工作报表。
- 关键字段/数据：任务标题、内容、来源、仓库、指派人、执行人、截止时间、选择项、完成说明、质检结果、评分和已阅记录。
- 安全校验/异常处理：员工只能访问本人或授权仓库任务；质检人不能篡改员工原提交；任务评分以 100 分为基准并保留计算明细。

### 低库存日历
- 业务规则：工作台展示授权仓库未来 30 天库存小于等于 1 的商品日期。
- 关键字段/数据：仓库、商品、日期、预计数量、风险原因和快照版本。
- 安全校验/异常处理：数据来自服务端库存快照，前端不得自行重算；快照过期时显示计算中而非旧值冒充实时值。

## 订单管理

完成从录单、库存时效判断、备货发货、租用跟踪、归还验机、售后、完结到取消追回的全生命周期闭环。

### 添加订单-基础字段
- 业务规则：录入姓名、昵称、收货人、地址、支付宝手机号、收货手机号、芝麻分、订单号、租期、来源、租金、备注、需求、单号、视频、天气风险。
- 关键字段/数据：客户、订单、租期、渠道、店铺、仓库、商品/套餐、SN、租金、备注、需求、物流、视频。
- 安全校验/异常处理：手机号、金额、日期、地址长度、芝麻分范围校验；敏感字段加密/脱敏。

### 添加方式-手工
- 业务规则：按品牌类型进入添加，减少先选品牌的操作成本；支持编辑记录、批注、置顶滚动、员工已阅取消置顶。
- 关键字段/数据：编辑前后值、批注文本、置顶状态、已阅人。
- 安全校验/异常处理：批注过滤脚本与敏感词；编辑核心字段必须记录审计。

### 添加方式-复制解析
- 业务规则：一键复制常规内容自动添加；常规字段上方，需手工选择字段下方；文本中有品牌型号时自动选择。
- 关键字段/数据：解析原文、字段映射、置信度、人工确认项。
- 安全校验/异常处理：解析结果必须人工确认后落库；保留原始文本快照。

### 添加方式-图片识别
- 业务规则：预留上传图片识别订单功能，前期可不开启。
- 关键字段/数据：图片、识别字段、置信度。
- 安全校验/异常处理：OCR 文件走上传安全白名单。

### 商品/套餐选择
- 业务规则：系统固定品牌型号；会员维护常用品牌型号；可添加型号、套餐、配件。
- 关键字段/数据：品牌、型号、套餐、配件明细、仓库。
- 安全校验/异常处理：不可由会员随意新增一级/二级品牌型号，防止数据污染。

### 库存可接单检测
- 业务规则：添加订单时根据租期范围、仓库、商品/套餐、物流路由判断可接单库存。
- 关键字段/数据：租期、发货日、归还日、仓库库存、在途库存、逾期库存。
- 安全校验/异常处理：库存扣占必须事务处理，避免并发超卖。

### 发货时效
- 业务规则：按发货仓、送达时间、承运商推荐上门时间；系统默认 10-11 点，可手工修改；租期前一天 17 点自动检测明日发货。
- 关键字段/数据：取件时间、预计送达、承运商、时效来源、确认状态。
- 安全校验/异常处理：人工时效与系统时效颜色区分；时效无法到达进入发货逾期风险。

### 仓库推荐
- 业务规则：A 仓库存不足时，如果 B 仓库存和时效满足，提示 B 仓发货；都不满足但总库存够，进入待选仓。
- 关键字段/数据：候选仓、库存、预计到达、建议理由。
- 安全校验/异常处理：跨仓切换需记录原因和操作者。

### 快递单号
- 业务规则：系统下单自动填单号；非系统下单人工填写；自动下单在上门前 2 小时触发，人工可取消/提前下单/改上门时间。
- 关键字段/数据：carrier, tracking_no, pickup_time, source, fee。
- 安全校验/异常处理：单号唯一；已关联订单不可被外部渠道覆盖。

### 发货视频匹配
- 业务规则：批量上传视频后识别 SN，成功匹配到未完成订单，失败提示二次检测和人工上传。
- 关键字段/数据：视频文件、检测 SN、订单、匹配状态。
- 安全校验/异常处理：客户可见视频需权限 URL；完结后按会员策略删除或保留。

### SN 绑定
- 业务规则：选择 SN 时若本仓没有，展示所在仓，可一键换仓或发起调货；扫码可直接回填。
- 关键字段/数据：sn_id, warehouse_id, order_id, bind_source。
- 安全校验/异常处理：SN 必须为在库可售；非在库状态禁止绑定。

### 归还验机
- 业务规则：非强制；可上传图片、选择划痕、填写新旧、赔付金额；有问题转售后，继续出租则更新库存。
- 关键字段/数据：验机图片、问题类型、新旧程度、赔付金额、配件缺失。
- 安全校验/异常处理：赔付金额进入记账簿；缺失配件按丢失/寄回分别处理。

### 确认收货/完结
- 业务规则：确认收货自动回补库存；可完结订单用于其他平台完结跟踪，已完结置灰。
- 关键字段/数据：完结时间、完结人、外部平台完结状态。
- 安全校验/异常处理：完结动作幂等；重复点击不能重复回补库存。

### 一键复制模板
- 业务规则：会员可设置 2 个复制模板，自定义字段和顺序。
- 关键字段/数据：模板名、字段列表、顺序、启用状态。
- 安全校验/异常处理：模板内容不得包含未授权敏感字段。

### 一键转发
- 业务规则：选择微信账号和好友，转发订单详情、客户详情、发货视频、理赔规则、使用说明、自定义话术、商家联系方式和小程序归还入口。
- 关键字段/数据：微信账号、好友、模板、快照、转发次数。
- 安全校验/异常处理：自定义话术需审核；理赔规则和视频做快照，防止事后篡改。

### 转寄订单
- 业务规则：A 订单转寄 B 订单后，B 自动继承 A 的发货仓与 SN，并按 B 租期重新计算时效。
- 关键字段/数据：source_order_id, target_order_id, sn_id, warehouse_id。
- 安全校验/异常处理：A/B 订单关系可追溯；SN 不允许同时被两个有效订单占用。

### 修改归还仓库
- 业务规则：修改客户归还仓后，SN 预计归还仓更新，新仓负责人收到提醒；误收到货可申请更新到本仓。
- 关键字段/数据：旧仓、新仓、原因、提醒状态。
- 安全校验/异常处理：客户小程序不可修改归还仓。

### 打印面单/码
- 业务规则：平台下单可批量打印平台面单；自下单打印订单码；所有订单都可打印码。
- 关键字段/数据：打印批次、打印人、订单列表。
- 安全校验/异常处理：批量打印需校验订单归属和仓库权限。

### 订单列表与筛选
- 业务规则：全部、租用中、逾期归还、待发货、发货在途、归还中、已签收、晚到、未知、渠道、商品、仓库。
- 关键字段/数据：状态、渠道、仓库、商品、日期、关键词。
- 安全校验/异常处理：列表默认脱敏；权限限定仓库。

### 渠道管理
- 业务规则：咸鱼、分单、淘宝、抖音、美团、京东、其他、联盟订单；会员可配置网页展示渠道。
- 关键字段/数据：渠道、店铺名、外部订单号。
- 安全校验/异常处理：外部渠道取消订单需同步删除/释放库存，避免占用。

### 发货/归还/到货列表
- 业务规则：今日、明日、后日小项入口；上午发货靠前；可按商品、人名筛选。
- 关键字段/数据：日期、仓库、状态、优先级。
- 安全校验/异常处理：仅显示授权仓库。

### 逾期规则
- 业务规则：归还逾期默认今日未完结即逾期，会员可设置 18 点未收到等规则；发货逾期默认 18 点前未发货或时效不赶趟。
- 关键字段/数据：规则类型、阈值、提醒方式。
- 安全校验/异常处理：规则变更只影响后续计算，历史结果保留。

### 售后概况
- 业务规则：可完结订单、售后中、售后丢失、售后损坏赔付、今日新增。
- 关键字段/数据：售后类型、进度、联系状态、金额、丢失物品。
- 安全校验/异常处理：售后完成后自动归类可完结；赔付进入记账簿。

### 取消/追回
- 业务规则：未发货订单可取消且排序不变；已发货不可取消，只能追回，填写原因并仓库告警。
- 关键字段/数据：取消原因、追回原因、仓库确认。
- 安全校验/异常处理：取消释放库存；已发货追回不直接释放库存。

### 我的工作台
- 业务规则：所有页面右侧展示工作图标，含管理设置任务和个人任务，超时提醒，同时展示仓库 7 天库存。
- 关键字段/数据：任务、截止时间、完成状态、仓库库存。
- 安全校验/异常处理：任务可见范围按权限组。

## 仓库管理与库存

将设备、配件、套餐、在途、预计到库和可接单能力统一核算，防止超卖和账实不符。

### 多维库存看板
- 业务规则：商品库存、套餐库存同栏展示，底部固定展示实时空闲小配件库存。
- 关键字段/数据：商品、套餐、配件、仓库、总量、空闲、占用。
- 安全校验/异常处理：所有统计从库存流水和订单状态计算。

### 在库空闲库存
- 业务规则：展示未被订单占用的 SN 设备数量 + 未占用配件个数。
- 关键字段/数据：free_sn_qty, free_accessory_qty。
- 安全校验/异常处理：报修、损坏、出售不计入空闲。

### 预计库存
- 业务规则：未来 30 天每日动态库存，每日独立重新核算。公式：总设备数 - 当日待发货 + 预计到库 - 租用中。
- 关键字段/数据：date, expected_in, pending_out, rented, available。
- 安全校验/异常处理：逾期归还统一归租用中；手动改归还时间后重算。

### 物流库存
- 业务规则：统计带归还单号设备 + 现有在库设备，按 12 点前、12-18 点、18-22 点展示。
- 关键字段/数据：route_node, estimated_arrive_time, time_bucket。
- 安全校验/异常处理：无物流信息沿用订单原始归还时间。

### 扣减规则
- 业务规则：设备报修、损坏、出售直接从总库存扣减。
- 关键字段/数据：status_change_reason, amount。
- 安全校验/异常处理：扣减必须写入库存流水；出售同步收益统计。

### 告警配置
- 业务规则：单商品设置低于百分比或低于个数告警；占用超过总库存 90% 标红。
- 关键字段/数据：threshold_type, threshold_value, notify_targets。
- 安全校验/异常处理：告警配置按会员/商品/仓库生效。

### 明细穿透
- 业务规则：点击任意库存数字弹窗展示占用库存的全部关联订单。
- 关键字段/数据：订单、SN、仓库、状态、租期。
- 安全校验/异常处理：穿透列表仍遵守订单权限和客户脱敏。

### 仓库分类统计
- 业务规则：全部仓库、实体分仓、联盟库存使用统一规则。
- 关键字段/数据：总库存、剩余库存、每日可接单。
- 安全校验/异常处理：联盟库存只共享 SN，不共享套餐。

### 可接单数量
- 业务规则：默认剩余库存为上限；可选按总库存 90%；可设置保护个数；不足 1 个记为 0。
- 关键字段/数据：stock_protection_qty, calculation_mode。
- 安全校验/异常处理：并发下单使用锁或库存预占，避免负库存。

### 自定义统计配置
- 业务规则：会员可选择品类是否参与统计、是否前台隐藏、展示顺序；小配件可隐藏。
- 关键字段/数据：show_frontend, include_stats, sort_order。
- 安全校验/异常处理：隐藏不等于删除；后台仍可追踪。

### 库存同步接口
- 业务规则：远期提供对外库存同步，会员可授权第三方平台调用库存下单扣减。
- 关键字段/数据：api_key, scopes, callback_url, stock_version。
- 安全校验/异常处理：必须有授权、签名、限流、幂等和回滚机制。

## 商品管理、SN 与套餐

建立可追溯的商品、SN、配件和套餐模型，支撑录单、库存、收益和周转统计。

### 商品首页
- 业务规则：固定排序：全部、在库空闲、发货在途、租用中、归还在途、设备报修、逾期归还、出库商品、续租商品。
- 关键字段/数据：状态、数量、筛选、导入导出、模板下载。
- 安全校验/异常处理：导入需校验品牌型号、重复 SN、必填字段。

### 库存基础模式
- 业务规则：主机类按 SN 单台录入；配件类支持 SN 模式和简易总数模式。
- 关键字段/数据：mode, sn_code, virtual_id, total_qty。
- 安全校验/异常处理：总数调小需手动删除并记录日志。

### 二维码/条码
- 业务规则：每个商品生成永久二维码和条形码，可自定义下载尺寸，二维码下方带编号。
- 关键字段/数据：code_type, code_value, download_size。
- 安全校验/异常处理：二维码只包含系统内部编码或短链，不暴露敏感信息。

### SN 档案
- 业务规则：主机强制逐条录入 SN；支持设备照片、最新 5 条照片、购买时间、成本、激活、保修、保险。
- 关键字段/数据：sn, photo, condition, purchase_at, cost, activate_at, warranty_until, insurance_until。
- 安全校验/异常处理：SN 全局唯一；保险到期前 1 个月提醒。

### SN 履历
- 业务规则：自动统计 SN 和套餐总租赁次数、近 3 个月使用记录、关联全部订单、发货视频使用频次。
- 关键字段/数据：order_count, recent_usage, media_count。
- 安全校验/异常处理：履历只追加，不覆盖。

### 价格与收益
- 业务规则：入库成本、出售售价、累计租金、回收进度条、型号回报率、投入产出比。
- 关键字段/数据：cost, sale_price, rent_income, roi。
- 安全校验/异常处理：出售 SN 删除前提示出售金额影响收益统计。

### PT3 规则
- 业务规则：PT3 主机强制 SN；一级/二级分类系统默认；会员可新增三级分类；官方配件双录入，非官方配件归 PT3 渠道配件。
- 关键字段/数据：category_l1/l2/l3, official_accessory。
- 安全校验/异常处理：会员新增分类需限定层级和命名长度。

### 通用配件
- 业务规则：配件可设置通用/不通用，例如同时适配 PT3 与 PT4。
- 关键字段/数据：compatible_product_ids。
- 安全校验/异常处理：套餐计算时按兼容范围扣减。

### 套餐配置
- 业务规则：套餐是录单快捷模板，不是独立实物库存；可按平台创建，也可不选平台创建，后续可修改平台。
- 关键字段/数据：platform, package_name, bom_items。
- 安全校验/异常处理：套餐可租数量由真实主机和配件池实时计算。

### PT3 套餐
- 业务规则：诚赁裸机、标准套餐、续航套餐；全能套餐；续航自定义；其他自定义。
- 关键字段/数据：主机数量、充电线、包、螺纹手柄、续航电池等 BOM。
- 安全校验/异常处理：下单选择套餐后同步占用通用配件。

### 租赁合作/商品出售
- 业务规则：展示发布的信息和收到的信息。
- 关键字段/数据：信息类型、商品、数量、状态、对方会员。
- 安全校验/异常处理：不与周转市场交易闭环混淆，必要时仅做信息展示。

## 极速核销台

用一个自动聚焦扫码输入框，覆盖入库、出库、盘点和顺丰码匹配，降低仓库操作复杂度。

### 扫码入库
- 业务规则：扫描设备 SN，自动匹配未完结订单；核对后点击完结，设备变更为在库可售；无订单则跳转添加设备。
- 关键字段/数据：sn_code, matched_order, action。
- 安全校验/异常处理：完结幂等；非本仓权限禁止入库。

### 扫码出库
- 业务规则：扫描 SN 校验库存，在库可售才通过；加载待发货且未录入 SN 的订单；绑定后订单已备货。
- 关键字段/数据：sn_code, order_id, status。
- 安全校验/异常处理：非在库状态禁止下一步。

### 订单页扫码备选
- 业务规则：订单页面点击 SN 输入栏后扫码自动回填并校验库存。
- 关键字段/数据：focused_field, sn_code。
- 安全校验/异常处理：校验失败弹窗并禁止保存。

### 库存盘点
- 业务规则：连续扫码；在库可售静默标记；系统非在库但实物在场弹窗疑似错放/外寄设备，手动匹配工单或订单。
- 关键字段/数据：scan_batch, abnormal_reason, remark。
- 安全校验/异常处理：盘点结束只导出异常清单，正常数据不展示。

### 扫顺丰码出库
- 业务规则：识别收件人首位手机号和姓匹配订单，自动填单号，人工确认并发货。
- 关键字段/数据：tracking_no, phone_prefix, name, matched_order。
- 安全校验/异常处理：匹配不到需人工选择；单号唯一。

### 扫顺丰码入库
- 业务规则：先用订单已有单号匹配；无单号再调用 API；超频展示查询中，下秒继续。
- 关键字段/数据：tracking_no, route_status, api_status。
- 安全校验/异常处理：顺丰和京东分别执行全站 10 次/秒限流，超出请求排到下一秒；单号匹配冲突时必须人工确认。

## 快递下单与物流路由

统一会员和客户归还快递能力，支撑时效判断、路线状态、库存预计到库和快递差价收入。

### 提供方优先级与接口治理
- 业务规则：顺丰提供时效、快递下单和同城急送，京东提供时效和快递下单，二者为主路由；快递 100/快递鸟为次路由；美团用于跑腿；天气接口补充发货地与收货地风险。
- 关键字段/数据：provider, capability, priority, rate_limit, timeout, retry_policy, fallback_provider, call_status。
- 安全校验/异常处理：顺丰和京东分别全站 10 次/秒，超限排队并返回查询中；所有调用保存请求摘要、响应摘要、耗时、错误码、重试和降级原因。

### 会员下快递单
- 业务规则：会员预充值后下单，最低余额 100 元；单次支付不限制；可按会员配置 9 折、8 折等结算折扣。
- 关键字段/数据：balance, discount, carrier, pickup_info, fee。
- 安全校验/异常处理：余额不足禁止下单；扣费流水不可变。

### 客户归还快递
- 业务规则：客户通过小程序归还，自动填写会员归还仓地址，定位寄件位置，可修改寄件人信息，不可改归还仓。
- 关键字段/数据：sender, receiver_warehouse, location, order_id。
- 安全校验/异常处理：手机号验证后只展示匹配订单。

### 物流状态
- 业务规则：会员端、客户端、后台展示待揽收、运输、签收、异常；长时间不揽收、退回、滞留标红。
- 关键字段/数据：route_node, status, abnormal_type。
- 安全校验/异常处理：异常提醒按会员和仓库权限推送。

### 路由用途
- 业务规则：订单路由查询、签收状态、归还状态、归还库存匹配、订单时效匹配。
- 关键字段/数据：tracking_no, eta, route_history。
- 安全校验/异常处理：接口失败可展示明确标记时间的最近缓存状态，同时提示数据可能过期；不得将缓存状态冒充实时结果。

### 时效检查
- 业务规则：录单默认使用承运商接口计算最晚发货时间；历史线路样本成熟后可用于初选；租期前一日 17:00 前分批复核明日订单，异常订单标红置顶并提醒。
- 关键字段/数据：origin_city, destination_city, ship_date, pickup_time, estimated_arrive, source_type, sample_count。
- 安全校验/异常处理：历史样本必须排除逾期到货订单；接口异常不能自动确认风险订单，需进入人工处理列表。

### 天气批处理
- 业务规则：订单列表展示首发地和收货地天气，实际发货日前一日 13:00-15:00 分批查询。
- 关键字段/数据：order_id, origin_city, destination_city, forecast_date, weather_risk, queried_at。
- 安全校验/异常处理：按城市和日期合并请求并缓存；失败进入重试任务，不阻断订单主流程。

### 闲鱼单号冲突
- 业务规则：系统已有单号时不再调取或覆盖闲鱼单号。
- 关键字段/数据：source_priority。
- 安全校验/异常处理：系统单号优先级最高。

### 物流赔付
- 业务规则：自动识别单号与赔付金额，退到会员账户。
- 关键字段/数据：claim_amount, tracking_no, member_wallet。
- 安全校验/异常处理：赔付与退款记录进入财务流水。

- 安全校验/异常处理：注销需二次确认；存在未完结订单/欠费/售后时禁止或进入冻结流程。

### 仓库设置
- 业务规则：设置仓库地址、负责人、取件规则、归还仓规则。
- 关键字段/数据：warehouse, pickup_rule。
- 安全校验/异常处理：仓库被订单引用后删除改为停用。

### 产品套餐设置
- 业务规则：维护常用品牌型号、商品、套餐和配件。
- 关键字段/数据：product_scope, package_template。
- 安全校验/异常处理：系统固定品牌型号与会员常用列表分离。

### 权限设置
- 业务规则：配置群组可看全部仓库或指定仓库，并限制操作范围。
- 关键字段/数据：permission_group, warehouse_scope, action_scope。
- 安全校验/异常处理：所有后端接口必须校验权限。

### 操作记录
- 业务规则：集中展示本商户新增、编辑和删除历史，编辑/删除记录保留原内容、变更内容、操作时间和操作人。
- 关键字段/数据：object_type, object_id, action, before_json, after_json, actor_id, operated_at。
- 安全校验/异常处理：查询强制当前 `tenant_id + member_id`；日志不可由商户编辑或删除。

### 回收站
- 业务规则：普通业务数据删除后保留 30 天，支持按条恢复；到期后由定时任务执行物理清理或合规归档。
- 关键字段/数据：对象类型、对象 ID、删除快照、删除人、到期时间、恢复人、恢复时间和恢复结果。
- 安全校验/异常处理：恢复前校验对象归属、引用关系和唯一约束；审计、财务、合同、协议和争议证据不进入回收站。

### 快递上门与逾期设置
- 业务规则：商户按仓库配置顺丰固定上门时间段；默认 18:00 未发货判定逾期发货，商户可在允许范围内调整。
- 关键字段/数据：warehouse_id, carrier, pickup_windows, overdue_cutoff, enabled。
- 安全校验/异常处理：规则变更只影响尚未确认发货时间的订单，已生成订单保留当时规则快照。

### 收发趋势设置
- 业务规则：配置只展示主商品、主商品加指定配件或指定套餐，并配置上下和左右展示顺序。
- 关键字段/数据：统计对象类型、对象 ID、显示开关、区域和排序。
- 安全校验/异常处理：只能选择本商户可用型号和套餐；停用对象自动退出新报表但保留历史统计。

### 库存保护设置
- 业务规则：支持全局最低百分比、单型号最低百分比和单型号保护个数；百分比结果不四舍五入，只向上取整。
- 关键字段/数据：scope_type, product_id, minimum_percent, protected_qty, effective_at。
- 安全校验/异常处理：百分比范围 0-100，保护数量非负；单型号规则优先于全局规则并保留规则版本。

### 渠道与来源设置
- 业务规则：订单来源可配置一级渠道和二级来源，名称、层级和顺序可调整；租仓联盟作为系统渠道按开通状态显示。
- 关键字段/数据：parent_id, level, source_name, source_type, color, sort, enabled。
- 安全校验/异常处理：系统来源不可删除；被订单引用的来源只能停用或改展示名，历史订单保存来源快照。

### 商品与赔付设置
- 业务规则：维护套餐、赔付模板、非平台标准型号和通用商品关系；赔付规则可从系统模板复制后由商户自行修改。
- 关键字段/数据：package_template, compensation_template, custom_model, common_product_scope。
- 安全校验/异常处理：商户不能修改平台标准品牌型号；赔付条款必须展示平台免责声明并保留发布版本。

### 联盟展示设置
- 业务规则：按联盟成员配置可见商品、可租库存比例，以及查看汇总库存或汇总加成员库存。
- 关键字段/数据：alliance_member_id, product_scope, visible_percent, view_mode。
- 安全校验/异常处理：比例按实际可租库存计算且不得超过 100%；成员退出或关系停用后立即撤销可见权限。

### 小程序、公开信息与订单展示
- 业务规则：配置商户一句话、联系方式公开开关、微信二维码、免押开关和订单卡片/精简列表展示方式。
- 关键字段/数据：merchant_slogan, contact_visible, wechat_qr, deposit_free_enabled, order_view_mode。
- 安全校验/异常处理：公开文案按平台风控规则审核；关闭公开后开放端立即不再返回联系方式。

### 视频保存策略
- 业务规则：设置发货视频完结后自动删除或保留时长；客户收货视频默认完结后保留 15 日且会员可见不可删。
- 关键字段/数据：retention_days, auto_delete。
- 安全校验/异常处理：超出免费 1G 空间后触发升级或清理提示。

### 账务管理
- 业务规则：充值、快递扣费、增值服务、发票、赔付、出售收入。
- 关键字段/数据：ledger, invoice_status。
- 安全校验/异常处理：财务流水只追加。

### 时效查询
- 业务规则：按仓库手工查询时效，免费工具。
- 关键字段/数据：origin_warehouse, destination, carrier。
- 安全校验/异常处理：查询限频。

### 在线表格
- 业务规则：提供会员自用表格能力。
- 关键字段/数据：sheet_id, owner。
- 安全校验/异常处理：只允许本会员访问。

### 记账簿
- 业务规则：归还验机赔付自动录入，卖出设备也计入。
- 关键字段/数据：amount, category, ref_order/ref_sn。
- 安全校验/异常处理：自动记录不可删除，只能备注或冲正。

### 二维码/条码生成
- 业务规则：自定义规格并下载。
- 关键字段/数据：content, size, format。
- 安全校验/异常处理：内容长度和类型校验。

### 记事本/我的工作台
- 业务规则：可发布多条个人或仓库工作内容，自定义标题、内容和已完成/已阅/未完成选择项，员工填写说明，管理执行抽检并生成 100 分制得分。
- 关键字段/数据：task, owner, warehouse, due_at, option, submission, review, score。

## 知识库、公告与复购管理

沉淀运营知识、公告通知和复购分析，提升重复使用效率。

### 品牌知识
- 业务规则：按品牌或商户自定义多级分类维护私有知识，可上传 PDF、图片和视频，支持置顶及全体员工/指定员工组阅读权限。

### 通用知识

### 公告
- 业务规则：平台公告可指定会员类型、生效和下线时间并需平台审核；商户内部通知仅本主体员工可见，可指定员工组、置顶、附件和动态顶端展示。

## 接口清单初稿

- **POST /merchant/orders**：创建本商户订单；客户信息、租期、商品/套餐、仓库、渠道；返回库存和时效校验；创建失败不占库存。
- **POST /merchant/orders/{id}/reserve-stock**：库存预占；强制订单归属和仓库权限；事务锁定并返回预占明细。
- **POST /merchant/orders/{id}/bind-sn**：绑定 SN；校验 SN 属于当前商户、授权仓库且状态在库可用。
- **POST /merchant/orders/{id}/ship**：确认发货；保存单号和媒体引用，原子更新订单、SN 和库存流水。
- **POST /merchant/orders/{id}/return-check**：归还验机；保存图片、成色、赔付和缺失配件，生成售后或可完结结果。
- **POST /merchant/orders/{id}/complete**：幂等完结并回补库存；重复请求返回原完结结果。
- **GET /merchant/inventory/availability**：查询租期内可接单库存；返回实时、预计、保护量、风险原因和推荐仓。
- **POST /merchant/warehouse/transfers**：发起调货；生成调货指令、SN 在途状态和目标仓通知。
- **POST /merchant/logistics/orders**：商户快递下单；从本商户账户扣费并写不可变流水。
- **GET /merchant/logistics/timing**：查询时效；网关或物流服务执行提供方级限流，超限返回查询任务 ID。
- **POST /merchant/work/tasks**：创建个人或仓库任务；支持指派、截止时间和选择项。
- **POST /merchant/work/tasks/{id}/submit**：提交完成说明或已阅结果；保留原提交。
- **POST /merchant/work/tasks/{id}/review**：管理抽检、备注和评分；不得覆盖员工提交。
- **GET /merchant/recycle-bin**：查询本商户 30 天内可恢复记录。
- **POST /merchant/recycle-bin/{id}/restore**：按条恢复并校验唯一约束和数据归属。
- **POST /merchant/knowledge/articles**：创建私有知识；版本、受众和附件占用配额由服务端处理。
- **POST /merchant/alliance/orders**：发起联盟协作订单；接收方只见规则允许的脱敏信息。
- **POST /merchant/market/posts**：发布周转信息；标准字段校验，拒绝私联和交易支付字段。
- **POST /merchant/media/upload-token**：获取本商户私有上传凭证；限制文件类型、大小和配额。
- **GET /admin/rental/members**：平台会员列表；按角色返回脱敏或完整字段，明文查看另行审计。
- **POST /admin/rental/members/{id}/certification/review**：审核认证并保存材料、结论和资格变更历史。
- **POST /admin/rental/agreements**：创建协议新版本；历史版本不可覆盖。
- **GET /admin/rental/audit-logs**：按日志域查询不可变审计；接口不提供删除和清空动作。
- **GET /admin/rental/finance/summary**：平台财务汇总；仅从账户和不可变流水聚合。
- **POST /admin/rental/disputes/{id}/freeze**：按预计赔付额冻结保证金；禁止超过工单核定额度。
- **POST /admin/rental/invoices/{id}/review**：审核开票申请；通过前校验同订单未成功开票。
- **POST /open/customer/sessions**：客户手机号/微信验证并确认指定协议版本，签发短期会话。
- **GET /open/customer/orders**：返回当前客户会话手机号匹配的订单，禁止传入商户 ID 绕过匹配。
- **POST /open/customer/returns**：创建归还物流单；归还仓从订单读取且客户不可修改。

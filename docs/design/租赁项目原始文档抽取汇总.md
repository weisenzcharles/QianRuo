## 9. 1.1版-库存周转市场---待定.docx

迁渃库存周转市场 完整功能规范定稿版

一、核心定位规则

1、会员支持一键上架全部自有库存，也可单独上架指定商品；上架商品仅做库存展示、同行查看，不参与平台交易、不做撮合接单。2、全程禁止会员自定义设置租金、接单金额，平台不展示任何租赁报价、日租月租价，从根源杜绝同行价格内卷、恶意压价。3、支持按发货城市筛选库存，以近 30 天周转次数作为商家、设备核心实力比拼维度，用周转数据替代价格竞争。4、新增平台地图视图，直观展示所有入驻会员地理位置，视觉清晰，方便同城同行快速对接调货。5、平台前台全程隐藏隐私及导流信息：坚决不展示报价、租金、微信、手机号、私人联系方式，杜绝公开页面裸奔引流。6、周转市场增设三大核心发帖板块：闲置出售、闲置出租、收购求购，仅做信息展示与站内私信撮合，不做订单、不做支付、不做交易担保，坚守平台不碰成交闭环的边界定位。7、所有板块发帖严格实行全下拉选择模式，关闭用户任意自由文字输入，仅可选择平台固定品类、品牌、型号、内存、成色、数量及预设区间，杜绝广告、导流、违规话术，发帖免审核、发布即刻展示。8、出售、收购类仅设系统固定价格区间可选，出租类不开放任何租金标价与金额填写，全程不靠定价引流，依靠库存实力与周转数据做良性竞争。

二、列表页卡片固定展示字段（简洁直观）

设备品牌 + 型号 + 内存版本设备成色（固定标准化选项：99 新 / 95 新 / 9 成新 / 85 新 / 有磕碰 / 有维修史），闲置可用库存数量，商家所在城市，近 30 天周转次数（核心排名、实力比拼指标），商品上架时间，服务状态标识标签（可代发 / 同城自提 / 长期批量合作 / 仅同行调拨），显示总多少台，按成色区分，显示什么成色多少台，闲置多少台，出租中多少台，长期未使用 N 台。

三、商品详情页额外展示内容

支持上传展示设备多张实拍图详细成色文字描述，标注有无磕碰、维修记录、国行 / 港版版本属性可租赁时间段、可调货调拨周期说明商家自定义备注（支持代发、同城自提、可长期批量合作等自主编辑填写）商家历史周转口碑标签（系统自动判定打标：高周转、履约靠谱、极速回复、长期供货）唯一沟通入口：站内私信按钮

四、增值配套功能

1.库存自主上下架管理会员可自主上架、下架闲置库存；可设置临时不可出借时段（自用 / 维修中），避免同行无效咨询。

2.多维度精准筛选支持按品牌、型号、成色、发货城市、可代发 / 同城自提标签多维度筛选，快速找同款、找同城货源。

3.同行店铺关注可关注意向同行商家，关注对象上新库存自动消息提醒，便于长期稳定调货合作。

4.机型上新订阅提醒可订阅指定设备机型，有同行同款库存上新，自动推送通知，不错过优质调货货源。

5.调拨意向一键登记无需先发私信，可直接提交调拨意向；商家后台可查看意向清单，减少无效闲聊、提升对接效率。

6.标准化成色模板统一固定成色选项，不用自定义乱描述，减少成色认知偏差、避免同行扯皮纠纷。

7.三大板块标准化发帖功能

2、预计库存

（1）每日独立重新核算数据，不沿用前一日数值，避免误差累积；计算公式：总设备数 - 当日待发货数量 + 预计到库数量 - 租用中数量，逾期归还设备统一归为租用中，配件套餐也是如此。

（2）依据订单发货、归还时间，自动测算未来 30 天每日动态库存。

（3）同步抓取归还物流节点（揽收成功、抵达本省、派送中、已签收），自动更新订单预计入库时间；无物流信息则沿用订单原始归还时间计算。

（4）逾期规则：订单到期未归还，次日标记逾期，逾期设备不计入可用库存，仍在租用中显示；会员手动修改新归还时间后系统重新核算库存；订单点击完结后更新库存：提前归还即时回补库存，无物流单号的逾期订单完结后设备直接入库。

（5）扣减规则：设备报修、损坏、对外出售，直接从总库存扣减对应个数。

（6）预警规则：商品 / 配件占用数量超过总库存 90%，标红预警。

3、物流库存（仅统计带归还单号设备 + 现有在库设备）

（1）总物流可到库库存 = 今日预计到库设备个数 + 当前在库空闲个数

（2）上午库存：12 点前完成签收到库，展示到库个数 + 在库空闲个数

（3）下午库存：12 点至 18 点完成签收到库，展示到库个数 + 在库空闲个数
